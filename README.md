# -Relationship-Analysis.

## Project Overview
This project analyzes the relationship between two numerical variables using a scatter plot.

## Objective
To understand how visualization reveals relationships between variables.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Scikit-learn

## Dataset
Iris Dataset

## Variables Selected
- X-axis: Sepal Length (cm)
- Y-axis: Petal Length (cm)

## Steps Performed
1. Imported required libraries.
2. Loaded the Iris dataset.
3. Explored the dataset.
4. Checked missing values.
5. Selected two numerical columns.
6. Created a scatter plot.
7. Calculated the correlation coefficient.
8. Analyzed the relationship.
9. Recorded three observations.
10. Saved the dataset as a CSV file.

## Observations
1. There is a positive relationship between sepal length and petal length.
2. As sepal length increases, petal length generally increases.
3. The scatter plot shows an upward trend, indicating positive correlation.

## Output
- Scatter plot
- Correlation coefficient
- Relationship analysis
- Three observations
- CSV dataset

## Conclusion
The scatter plot shows a positive relationship between sepal length and petal length. This project demonstrates how Python visualization tools help analyze relationships between numerical variables.

## How to Run
1. Open Google Colab.

3. Run all cells.
4. View the scatter plot and results.
